🔒 Kebijakan Privasi
Keamanan data & privasi pengguna DIS-NRW

1. Penyimpanan Data Lokal

Semua riwayat dokumentasi foto dan data input disimpan secara lokal pada peramban perangkat Anda menggunakan teknologi IndexedDB (localForage). Data laporan tidak diunggah ke server pihak ketiga manapun tanpa izin Anda.

2. Izin Lokasi (GPS) & Kamera

Aplikasi membutuhkan izin akses GPS semata-mata untuk membubuhkan koordinat titik pekerjaan dan alamat pada watermark foto. Izin Kamera digunakan langsung di perangkat Anda untuk mengambil foto bukti pekerjaan.

3. Pemrosesan AI Gemini

Saat Anda menggunakan fitur auto-caption AI, foto dikirimkan secara terenkripsi (HTTPS) ke endpoint resmi Google Gemini API hanya untuk menghasilkan ringkasan 1 kalimat deskripsi pekerjaan.
